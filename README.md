# 八维行业分析（Eight-Dimension Industry Analysis）

> **多源投研数据驱动的八维行业分析引擎**：输入一家公司名或一个行业名，自动产出覆盖**产业生命周期、商业模式、市场规模、护城河、竞争格局、估值、外部因素、景气度**八大维度的完整 HTML 分析报告。
>
> 方法论改编自肖璟《如何快速了解一个行业》（前麦肯锡分析师），核心是**以产业生命周期为轴心，按渗透率划分阶段，不同阶段自适应分配八维分析权重**的有序分析体系——不是"把所有信息收集一遍"，而是"在不同阶段侧重不同维度"。

## 🧱 分析框架总览

### 轴心：产业生命周期（渗透率划分法）

> **渗透率 = 存量用户（或年销量）÷ 潜在客户群（或理论总容量）**。以渗透率为**主判据**、增速（曲线斜率）为**辅助交叉验证**。

| 阶段 | 渗透率区间（左闭右开） | 增速辅助特征 | 核心分析重点 | 一句话特征 |
|------|----------------------|--------------|-------------|-----------|
| **导入期** | x < 15% | 技术路线未定，大量新进入者，亏损为主 | 技术可行性、商业模式验证、政策催化 | 路走得通吗？ |
| **启动区间** | 15% ≤ x < 20% | 渗透率开始快速爬升，资本涌入，龙头未定 | 临界点附近，政策/成本拐点可能触发加速 | 要加速了？ |
| **成长期** | 20% ≤ x < 35% | 渗透率快速提升，龙头初现，收入高增长 | 市场规模增速、竞争格局演变、估值方法 | 天花板够高吗？ |
| **成熟期** | 35% ≤ x < 60% | 增速放缓、格局稳定、利润释放 | 护城河深度、盈利质量、集中度提升（第二曲线） | 会被替代吗？ |
| **存量博弈** | 60% ≤ x < 70% | 总量见顶，只剩份额再分配，价格战高发 | 份额再分配、价格战 | 还能抢多少？ |
| **衰退期** | x ≥ 70%（或负增长） | 需求萎缩、替代品出现 | 替代风险、转型可能、清算价值 | 还能活吗？ |

> ⚠️ 边界值取左闭（渗透率恰好 35% 记为成熟期）。禁止「15-20 / 20-35 / 35-40+」这类重叠写法。**本表是 skill 内唯一生命周期阈值定义，禁止另写阈值**。

## 📐 八维度详解（每个维度的判据 / 公式 / 推导）

> 每个维度章节**开头必须先放「方法卡」四行结构**（📌回答什么问题 / 🔬用什么方法判 / 📏判据是什么 / 🔧需要哪些数据），再输出结论与推导。判据一律以 `references/book-criteria.md` 为唯一锚点，禁止在报告里另写阈值。

### 维度 1 · 行业概览与生命周期定位

- **回答**：行业处在「幼年/青年/中年/老年」哪个阶段？
- **方法**：渗透率划分法（主判据）+ 增速交叉验证
- **核心公式**：`渗透率 P = 当前年销量(或用户数) ÷ 理论总容量`；`渗透增速 g = (今年P − 去年P) ÷ 去年P`；`空间余量 = (1 − P) × TAM`
- **要点**：行业定义与产业链图谱（上中下游）、生命周期阶段判定（可点击 `<details>` 折叠展示计算过程）、**一级市场资本动向**（融资/IPO/并购反映行业冷热，注意区分二级市场价格）、行业关键里程碑
- **双口径判定**：国内外阶段差异显著时须分市场分别判定（如「国内成熟 · 国外成长期」）
- **小白翻译**：渗透率就像「智能手机在人群里的普及率」。10 人里 1 人用=刚起步；5 人用=正疯涨；9 人用=只能抢别人客户。

### 维度 2 · 商业模式可行性

- **回答**：这门生意怎么把钱赚到手？扩规模后会不会更赚？
- **方法**：顺流拆解（进什么料→做什么→卖给谁→怎么收钱→留下什么）+ 最小运作单位 UE 模型
- **核心公式**：`UE（单位经济，卖一个能赚多少）= 客单价 − 单客直接成本(料+工) − 单客间接摊销(获客+管理+研发)`；`毛利率 = (收入−直接成本) ÷ 收入`；`CCC（现金循环周期，垫钱到收回要等多少天）= 存货周转天数 + 应收周转天数 − 应付周转天数`
- **判据**：UE > 0 才值得规模扩张，否则「规模越大亏越多」；CCC 越短越健康
- **需求真伪四步验证**：① 卖出去（需求真实？刚需还是伪需求）→ ② 赚到钱（UE 是否跑正）→ ③ 持续赚（能否大规模复制）→ ④ **付费意愿**（用户多 ≠ 好生意，须有相当比例愿意付费；免费规模再大无付费意愿即伪需求）
- **小白翻译**：重点不是「赚不赚钱」，而是「每多接一单是不是更赚」。UE>0=卖一个赚一个；UE<0=卖得越多亏越多。

### 维度 3 · 市场规模与空间

- **回答**：生意天花板多高？离天花板还差多少空间？
- **方法**：TAM/SAM/SOM 阶段化 + 自上而下 × 自下而上两法交叉验证
- **核心公式**：`TAM（总潜在市场，理论天花板）= 所有人 × 客单价`；`SAM（可服务市场，能碰到的块）= 目标人群 × 客单价`；`SOM（可获得市场，已吃下的份额）= 基于份额推算`；`CAGR（复合年增速）= (终值 ÷ 初值)^(1/年数) − 1`
- **阶段化空间逻辑（必写）**：成长期看 `SAM÷TAM`（≈渗透率，判高增长还能持续多久）；成熟期看 `SOM÷SAM`（市占率，逻辑转集中度提升）；`空间余量 = (1 − 当前渗透率) × TAM`
- **两法交叉验证（必做）**：自上而下（总量×渗透率×客单价）与自下而上（单客户价值×客户数×玩家数）同时测算，**差距 >30% 必须解释口径差异**；取两法重叠区间为市场规模，避免单一数字虚假精确
- **小白翻译**：TAM 是理论最大盘子，SAM 是你能碰到的块，SOM 是你已吃下的。关键不是盘子多大，而是「还能长多久」。

### 维度 4 · 护城河与防守性

- **回答**：公司有没有挡住对手的真城墙？还是只是暂时跑得快？
- **方法**：**5×4 生产要素 × 生产关系矩阵**——逐格判断公司在哪一格具备别人难复制的优势
- **5×4 矩阵**（生产要素 ＼ 生产关系）：

| 生产要素 ＼ 关系 | 政府 | 同行 | 供应商 | 客户 |
|----------------|------|------|--------|------|
| 劳动力 | — | 人才壁垒 | — | — |
| 土地/资源 | 牌照/矿权排他 | 区位垄断 | — | — |
| 资本 | 融资便利 | 规模门槛 | — | — |
| 技术 | — | 专利护城河 | — | 技术黏性 |
| 数据 | — | — | — | 转换成本/网络效应 |

- **护城河成立三问（必跑）**：①难复制？②可持续？③对手无法用钱买断？任一不满足则该格优势不成立
- **铁律：成本优势是结果不是原因**——凡写「成本低」，必须追问低成本来自哪个要素/关系（技术？规模？资源？），落到矩阵具体格；能用钱买断的优势不是真护城河
- **辅助识别**：ROIC（投入资本回报率，看资本赚不赚钱）长期高于行业平均 → 有护城河（结果侧印证）
- **成熟期重点**：防守性是成熟期第一权重——"一旦出现了被替代的可能，行业的投资逻辑也会发生变化"
- **小白翻译**：别只说「有品牌、有成本优势」这种形容词，要问「优势到底来自哪？对手花钱能不能马上抄走？」。能用钱买断的优势，都不是真护城河。

### 维度 5 · 竞争格局与盈利性

- **回答**：蛋糕被几家分？格局固化没？龙头稳不稳？
- **方法**：CRn 集中度 + 梯队划分 + 波特五力（简化为对手/上下游/替代品）
- **CR8 三分类（书中最好用的一把尺子）**：

| CR8（前 8 家市占率之和） | 格局类型 | 含义 |
|------------------------|---------|------|
| CR8 < 40% | **竞争型** | 玩家散、价格战频发、座次未定，变数大 |
| 40% ≤ CR8 < 70% | **低集中寡占型** | 龙头初显，集中度在提升，是「押注赢家」好窗口 |
| CR8 ≥ 70% | **极高寡占型** | 格局固化，龙头定价权强，但超额收益已被 price in |

- **横向格局**：TOP10 玩家份额与同比变化、竞争烈度、**产业地图与潜在颠覆者**（主导者/挑战者/颠覆者角色定性框）
- **纵向格局**：产业链利润分配（微笑曲线：哪个环节最赚钱）、上下游议价能力对比、利润转移趋势
- **必须列可比公司**：≥3 家可比公司份额/盈利对照表（P0-7 门禁），禁止"竞争激烈"式形容词糊弄
- **小白翻译**：CR8 是「前 8 家加起来的份额」：低于 40% 大家在混战；40%–70% 龙头刚冒头还在抢地盘（研究价值最高）；超 70% 座次已定，好东西价格也早被市场知道。

### 维度 6 · 估值分析

- **回答**：公司现在卖得贵不贵？相对自己和同行在什么位置？
- **方法**：总公式 `市值 = 净利润 × 估值倍数`；再按阶段选 PE / PEG / PB / PS
- **核心公式**：`PEG = PE ÷ (未来3年净利CAGR × 100)`（PEG<1 相对便宜）；`隐含回报 = 1÷PE + 增速`
- **阶段化估值法（与生命周期联动）**：

| 阶段 | 推荐估值法 | 原因 |
|------|-----------|------|
| 导入期 | P/S、PEG、情景 DCF | 无利润，只能看收入 |
| 成长期 | PEG、P/S、EV/Revenue | 利润尚不稳，收入增速更关键 |
| 成熟期 | PE、PB、股息率、DCF | 利润稳定，传统估值有效 |
| 衰退期 | PB、清算价值、股息率 | 关注资产底部 |

- **双视角（必给）**：同时给「相对（同业分位）+ 绝对（历史分位）」结论，禁止只给单一 PE
- **低估值陷阱（必排）**：周期股须验证当前盈利是否处高点（**高点低 PE 是假便宜**）；低 PE 须验证盈利是否可持续（价值陷阱）
- **小白翻译**：公司总价值 = 每年赚的钱 × 一个倍数。光看 PE 会踩坑：周期股利润最高点时 PE 反而最低（假便宜）。必须同时看「比同行贵不贵」和「比自己历史贵不贵」。

### 维度 7 · 外部驱动力（PEST）

- **回答**：行业外面的风（政策/经济/社会/技术）会怎么吹动这门生意？
- **方法**：PEST 五段传导链——**每个外部因素必须走完五段**，不再只罗列现象
- **五段传导链（必走，P1-1 门禁）**：① 事实（发生了什么，带来源日期）→ ② 传导路径（怎么一步步影响收入/成本）→ ③ 影响对象（收入端/成本端/估值端）→ ④ 量级（±X% 净利，无法量化标「定性待跟踪」）→ ⑤ 兑现时点（何时见效，区分**已落地 vs 仅预期**）
- **P**：政治/监管/地缘 | **E**：经济/利率/汇率/通胀 | **S**：社会/人口/消费习惯 | **T**：技术突破/颠覆
- **小白翻译**：过去只说「政策利好」是废话。正确做法是把风怎么吹进窗户说清楚：补贴退了→车变贵→买的人少→少赚 X%→明年见效。**说不出传导路径的「利好」基本是安慰剂。**

### 维度 8 · 景气度跟踪

- **回答**：生意现在热不热？升温/筑底/降温？拐点快到了吗？
- **方法**：景气指标看板——每行业定制 3-5 个核心指标（量/价/库存/订单/产能）+ 跟踪频率 + 拐点信号
- **指标看板框架（须按行业定制）**：

| 维度 | 代表指标 | 频率 | 上行信号 |
|------|---------|------|---------|
| 量 | 产量/出货量/装机量（同比） | 月/季 | 同比加速 |
| 价 | 产品单价/吨利润（环比） | 周/月 | 环比上涨 |
| 库存 | 产成品存货同比 | 月 | 同比去化（下降） |
| 订单 | 新订单指数/招标量 | 月 | 持续放量 |
| 产能 | 产能利用率 | 季 | 回升至高位 |

- **拐点信号**：任一指标**连续 2 期反转** + 库存周期位置 + 产能利用率 → 趋势变天确认（往往早于新闻）
- **纵向指标**：产业链上下游景气传导与时滞（上游原材料价格 → 中游产能利用率 → 下游需求订单）
- **小白翻译**：光说「行业景气」没用，得说清看哪几个温度计、多久量一次、什么读数算变天。最值钱的是拐点信号：指标连续两期反转，往往比新闻早一步告诉你趋势要变。

## 🔄 完整工作流（Phase 0 → 4）

```
Phase 0    确认分析目标（行业颗粒度 + 地域范围 + 案例锚点公司）🔴 CHECKPOINT
Phase 0.5  假设前置与专家访谈准备（3-5 条研究假设 + 专家四件套）【防偏差核心】
Phase 1    多源数据采集（A/B/C/D/E 五组并行，4-5 轮完成）🔴 CHECKPOINT
Phase 1.5  视觉主题（统一 Analytics Blue 金融风，自动执行）
Phase 2    八维度并行深度分析（每维度按强制输出模板，含五件套）
Phase 3    综合结论（信号快照 + 维度冲突 + 反共识检验 + OIE 迭代待办）
Phase 3.5  质量门禁（跑 check_report.py，P0 不过阻断发布）
Phase 4    报告组装与图表实例化（C1/C2/C3 三图强制）
```

### Phase 0.5 防偏差机制（本 skill 特色）

- **A. 研究假设清单**（3-5 条）：每条含 `假设陈述 + 验证方式 + 当前置信度`，带着假设去采集，避免被海量信息淹没（先假设后研究原则）
- **B. 专家访谈四件套**：行业术语表 / 想验证的假设 / 追问路径（从宽到窄）/ 开放性提问；无法触达专家则标注「⚠️ 未做专家验证」并在反共识检验中列为认知盲区
- **C. 专家优先原则**：公开信息是起点，深度洞察靠专家一手认知

### Phase 3 综合结论（必含 7 项）

1. 执行摘要（150 字内：行业阶段 + 核心矛盾 + 综合倾向）
2. 行业吸引力评级（高/中/低）+ 核心理由
3. 生命周期定位总结（一句话）
4. 关键风险提示（≥3 条，按影响排序）
5. 投资启示（观察方向，**不构成买卖建议**）
6. 待跟踪指标（3-5 个，含当前值 + 触发阈值 + 触发含义）
7. **OIE 认知迭代待办**（回写假设清单中最该优先验证的 2-3 条 + 验证路径）

**信号快照表**：8 维度各给 🟢/🟡/🔴 评级 + 置信度 + 一句话核心理由 → 统计偏多/中性/偏空。

**维度冲突检测**：检查是否存在评级相反且都是高置信度的对立维度——这是行业分析中最有价值的信息（如市场规模 🟢 但竞争格局 🔴 → 行业扩容但格局恶化，关键看龙头能否守住份额）。

**反共识检验（必须执行）**：所有正面结论得出后，强制切换到最悲观立场系统挑战自己——≥200 字，≥2 个具体「推翻信号」（可观测的事件/数据变化），禁止泛泛而谈。

## 🔍 数据源依赖

| 依赖 | 必需 | 说明 |
|------|------|------|
| `westock-data` | 核心（A股/港股） | 行业分类、成份股、财报、研报、一致预期 |
| `neodata-financial-search` | 推荐 | 行业级金融语义搜索（总量/估值/景气度） |
| `WebSearch` / `WebFetch` | 必需 | 公开信息兜底（或经 `web-access` skill） |
| `wechat-article-search` | 可选 | 微信深度文章 |
| `competitive-analysis` | 可选 | 结构化竞争格局 |

**搜索优先级**：① `westock-data`（结构化数据）→ ② `neodata-financial-search`（金融语义搜索）→ ③ `WebSearch`/`WebFetch`（公开信息兜底）。

> 非 A股 / 全球行业场景以 `WebSearch/WebFetch` 为主，`westock-data` 仅作参考，报告会标注覆盖面局限。

**数据采集纪律**：
- **六元组记录制**：每条数据必须记录 `{数值, 口径说明, 来源URL, 页面标题, 发布日期, 抓取日期}`，缺任一项不得写入报告
- **交叉验证**：关键数字（渗透率/CR/规模/PE）至少 2 个独立来源，否则标 `[待验证]`
- **时效性**：优先近 6 个月研报，超 1 年标 `[过时]`
- **链接四级颗粒度**：L1 页面级（带锚点）/ L2 文档级（带页码）/ L3 查询级（带参数）/ L4 无链接（降级署名 + 来源表登记）；**唯一验收标准：点开链接能 Ctrl+F 搜到被引用的那个数字**

## 📤 输出格式

| 用户说 | 产出 | 说明 |
|--------|------|------|
| （默认，什么都不说） | **HTML** | 单文件交互式报告，浏览器直开，含打印样式 |
| 「要 PDF / 要打印版」 | HTML + PDF | 浏览器 Cmd/Ctrl+P 另存 |
| 「要 Markdown / 存档 / 给别的 AI」 | HTML + MD | 由 HTML 提取，避免不同步 |

**HTML 报告结构**：报告头 → 执行摘要 → 八维卡片（dim1-dim8）→ 综合结论（信号快照 + 维度冲突 + 反共识 + OIE 待办 + 跟踪指标）→ 数据来源汇总。

**每维度强制输出模板**（不可省略任何一项）：方法卡 → 核心结论（≤30字）+ 评级徽章 → 可信度档位徽章 → 关键数据（2-3 个硬数字带来源）→ KPI 趋势 → 推导过程（默认展开）→ 分析正文 → 人话卡 → 反面假设 → 竞品对照（仅维5）→ 洞察 → 风险警示 → 盯什么（2-3 条行动要点）→ 数据来源。

**强制三图表**（C1/C2/C3，缺一不可，防回归）：
- **C1** 市场规模双序列柱状图 + 数据表（维度三）
- **C2** 可比公司 PE 对比条形图（维度六，锚点公司金色高亮）
- **C3** 八维评级雷达图（综合结论，8 轴评分严格等于信号快照表）

## 🛡️ 质量门禁（发布前硬卡）

`references/check_report.py` 机械执行（Python 标准库，零依赖）：

| 级别 | 含义 | 关键规则 |
|------|------|---------|
| **P0** | 阻断发布 | P0-1 八章方法卡齐全 / P0-2 八章推导齐全 / P0-3 关键数字可复算 / P0-4 链接覆盖率≥90% 且非纯域名 / P0-5 护城河用 5×4 矩阵+三问 / P0-6 生命周期阈值用正确表（15/20/35/60/70+）/ P0-7 可比公司表≥3家 / P0-8 估值双视角+排除陷阱 |
| **P1** | 发布前必改 | P1-1 PEST 五段链 / P1-2 景气指标看板完整 / P1-3 规模两法交叉验证 / P1-4 结构完整可解析 |
| **P2** | 优化项 | 小白翻译+章末一句话 / 打印样式 / 来源汇总表 |

> **元原则**：凡是重要规则，必须能被程序检查；不能被检查的规则等于建议。门禁硬卡在 Phase 3（输出前），不是写完再自检。

- 深色 Hero（三段深空蓝渐变 + 金色底边 + 紫金曲线纹理）
- 右上角 🌙/☀️ 深色切换（localStorage 持久化）
- 目录卡（毛玻璃）+ 桌面侧栏导航 + 移动端进度条
- 每维度卡：数字水印 step-head（180px 半透明大数字）+ 大标题 + 紫金顶条
- 方法卡（紫蓝渐变底 + 左紫金条）、KPI 卡（紫金渐变顶条）、人话卡（浅紫底）、反面假设（灰底）、风险卡（三色左条）、结论框（金色渐变）
- 徽章体系：评级 `rating-buy/hold/sell`（看好=绿/中性=金/谨慎=红）、可信度档位 `tier-rich/medium/lean/online`、来源状态 `status-badge`

**中国惯例**：行情数据涨红跌绿（涨=`#d63384` 红 / 跌=`#16a34a` 绿）；评级语义看好=绿、谨慎=红（国际惯例）。二者不冲突——一个是行情方向，一个是态度判断。

**排版规则**：并列信息项必须分行（禁止顿号挤一行）、表格强制 `.table-wrap` 容器、单段 ≤120 字、Hero 副标题不截断。

**离线可用**：禁止外部字体/CDN，SVG 自包含，双击 HTML 可离线渲染；打印样式已内置（隐藏导航、折叠展开、图表不跨页）。

## 🚀 安装与使用

### WorkBuddy（主要平台）

```bash
# 1. 把本仓库复制到 WorkBuddy skills 目录
cp -r eight-dimension-industry-analysis-sy ~/.workbuddy/skills/

# 2. 在 WorkBuddy 对话中触发
# "用八维行业分析 分析一下 新能源汽车行业"
# 或 "分析 宁德时代 所在行业"
```

### 其他 Agent（Claude Code / Cline 等）

本仓库是标准 `SKILL.md` 格式的 Agent Skill，任何支持该约定的 Agent 均可直接加载：
- 将本仓库放入你的 Agent 的 skills 目录（如 Claude Code 的 `.claude/skills/`）
- 调用时会自动读取 `SKILL.md` 主流程 + `references/` 判据锚点执行
- 注意：部分数据源（`westock-data` / `neodata-financial-search`）为 WorkBuddy 生态能力，其他 Agent 环境下会自动降级为 `WebSearch`/`WebFetch` 兜底，报告仍可产出但标注数据覆盖面局限

### 手动触发（无依赖兜底）

所有数据源不可用时，skill 会输出八维框架 + 分析提示并标注「⚠️ 数据采集失败」，不卡死。
