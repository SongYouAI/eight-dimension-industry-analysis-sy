# 八维分析 · 输出规范（output-spec）

> 本文件规定报告的**输出格式**与**数据来源链接颗粒度**。替代旧版「必须输出三件套（HTML+MD+PDF）」硬约束（见 SKILL.md 输出格式段）。
> 配套 [quality-gate.md](quality-gate.md) P0-4（链接邻近率）与 [data-requirements.md](data-requirements.md) 六元组。

---

## 零、视觉与结构契约（v3 强制）

1. **单文件 HTML 自带 v3 皮肤**：`<head>` 末尾必须有 `<style id="hydro-skin">`（由 `render_report.py` 注入 `assets/hydro-skin.css`），不得依赖外部 CSS/字体/CDN。视觉规格见 [hydro-design-spec.md](hydro-design-spec.md)。
2. **Hero 由生成器产出**：含 `.hero-masthead / .hero-art / .hero-content / .hero-foot`；数据文件只给 `hero` 字段（缺省由 `meta` 推导），禁止手写 `<div class="hero">`。
3. **结构闭合**：所有片段必须经 `scripts/html_helpers.py` 的严格闭合构造器生成；渲染前 `validate_data_fragments()`、渲染后 `validate_document()` 双检；门禁 P0-11 兜底。
4. **动效与脚本**：入场只改 transform；`<script>` 内不得有来源角标；交付前 `node --check` 通过。
5. **明暗与打印**：`data-theme` 仅 light/dark，暗色 token 反相；打印回落亮色、隐藏导航与装饰。

## 一、输出决策表（默认 HTML，按需扩展）

| 用户说 | 产出 | 说明 |
|--------|------|------|
| （默认，什么都不说） | **HTML** | 单文件，含打印样式，可直接浏览器打开/分享 |

## 二、可核查链接 · 四级颗粒度

**唯一验收标准**：点开链接后，在该页面上能**直接找到被引用的那个数字**（可 Ctrl+F 搜到，或在页面明示的图表/表格中）。做不到即不合格。

| 级别 | 要求 | 正例 | 反例 |
|------|------|------|------|
| **L1 页面级** | 点开直接看到被引数字 | `.../report-2026.html#shipments` | 机构官网首页 |
| **L2 文档级** | PDF/研报带页码锚点 | `.../industry.pdf#page=12` | 只写「来源：XX 研报」 |
| **L3 查询级** | 数据库带参数直达指标表 | `.../data?ind=cr8&year=2025` | 数据库域名首页 |
| **L4 无链接** | 降级写法 + 来源表登记 | `协会 · 《XX 年报》· 2026-03 · P8` | 裸机构名无出处 |

**链接策略**：

1. 权威源给官方披露页；研报/新闻给稳定摘要页。
2. 无稳定 URL 则保留「来源名+标题+日期+页码」署名（L4），禁止裸名、禁止编造。
3. 报告末尾必须有「数据来源汇总」锚点区（id=`src-summary`），含全部六元组字段，无链接项标「无公开链接」。

## 三、HTML 报告结构约定

- 吸顶导航覆盖全部维度章节 + 综合结论。
- 每维度章节内顺序：📐方法卡 → 🎯核心结论+评级 → 📊关键数据（带口径） → 🔍推导过程（默认展开） → 📝深度分析 → ⚖️反面视角 → ⚠️风险与推翻信号 → 💬本章一句话 → 🔗数据来源。
- 打印样式（`@media print`）：隐藏吸顶导航、折叠块强制展开、图表不跨页断裂，确保「打印即 PDF」质量可接受。

---

## 四、数据截止时点与口径（P1-6 门禁）

行情、估值、市值、股价、PE/PB 等**时点敏感数据**必须在报告头声明数据截止时点，格式 `YYYY-MM-DD HH:MM`，并标注口径。

| 数据类型 | 必须标注 |
|---|---|
| 股价 / 市值 / PE / PB | 截至时点 + 收盘价或盘中价 + TTM/静态 |
| 财报数据 | 报告期（如 2026Q3）+ 口径（合并/母公司） |
| 行业总量 / 渗透率 | 统计年份 + 来源发布日期 |

- Hero 元信息放「数据截至」一项（如 `2026-11-08 22:27`），页脚保留「分析日期」。
- 门禁 `P1-6` 机械校验报告头含 `20YY-MM-DD HH:MM` 且出现「截至 / 截止 / 数据时点」。
- 混用不同截止时点的数据时，必须在「数据来源汇总」逐条标注，不得只给一个全局时点。
