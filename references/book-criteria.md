# 八维分析 · 书中判据总表（book-criteria）

> 本文件是八维行业分析 Skill 的**判据锚点**。所有维度的判断标准、阈值、公式、分类矩阵一律以本文件为唯一依据，禁止在 SKILL.md 或报告里另写阈值、禁止口径漂移。
> 方法论源：肖璟《如何快速了解一个行业》（2025）。凡与书冲突处，以本文件 + 书原版为准。

---

## 使用铁律

1. **唯一依据**：报告里出现任何阈值/公式/分类，必须能在本文找到出处。
2. **先验证后下判**：每个维度的「判断句式」必须可由本章「字段级取数公式」复算，禁止只给结论不给推导。
3. **口径一致**：TAM/SAM/SOM、渗透率、CRn 的口径全文统一，跨维度不得混用。
4. **成本优势是结果不是原因**：凡写「成本低」，必须追问低成本来自哪个生产要素/生产关系（技术？规模？资源？），落到 5×4 矩阵具体格。

## 维度 1 · 产业生命周期（渗透率划分法）

**方法卡**

| 项 | 内容 |
|----|------|
| 回答什么问题 | 行业处在「幼年/青年/中年/老年」哪个阶段？ |
| 用什么方法判 | 渗透率划分法：渗透率 = 存量用户(或年销量) ÷ 潜在客户群(或理论总容量)；以渗透率为**主判据**、增速(曲线斜率)为**辅助交叉验证** |
| 判据是什么 | 下方阈值表（书原版，已修正 framework-detail.md 旧错表） |
| 需要哪些数据 | 当前年销量/用户数、理论总容量/潜在保有量上限、去年渗透率（算增速） |

**书中阈值表（唯一）**

| 渗透率区间 | 阶段 | 书中断言的关键特征 |
|-----------|------|-------------------|
| x < 15% | **导入期** | 技术路线未定，玩家少，高风险高赔率；只看赛道空间，不讲利润 |
| 15% ≤ x < 20% | **启动区间** | 临界点附近，政策或成本拐点可能触发加速，波动最大 |
| 20% ≤ x < 35% | **成长期** | 渗透快速爬坡，增速最快——最重要的「甜蜜区」，研究价值最高 |
| 35% ≤ x < 60% | **成熟期** | 渗透放缓，增速见顶；增长逻辑从「渗透率」切换为「集中度提升 / 第二曲线」 |
| 60% ≤ x < 70% | **存量博弈** | 总量见顶，只剩份额再分配，价格战高发 |
| x ≥ 70%（或 70%–80%） | **衰退期** | 需求趋势性下滑，除非有替代技术重生 |

> 注：书以 35% 为「进入成熟」门槛、40% 以上为成熟主体；本表合并为「35%–60% 成熟期」并补「60% 存量博弈 / 70%+ 衰退」锚点，与原书精神一致。边界值取左闭（渗透率恰好 35% 记为成熟期），禁止「15-20 / 20-35 / 35-40+」这类重叠写法。衰退期亦可单独以增速判（行业整体负增长、需求萎缩、替代品出现）。

**字段级取数公式**

```
渗透率 P = 当前年销量(或用户数) ÷ 理论总容量(或潜在保有量上限)
渗透增速 g = (今年P − 去年P) ÷ 去年P
空间余量 = (1 − P) × TAM   # 见维度3
```

**推导模板（六行式，报告内默认展开）**

1. 取数：从行业报告/协会取「当前年销量」「理论总容量」，记录来源 URL 与发布日期。
2. 口径：明确「总容量」口径（保有量上限 or 政策规划目标），避免分子分母不可比。
3. 计算：套公式算 P 与 g，保留两位小数。
4. 对照阈值：把 P 落到上表读阶段；用 g 读「加速还是减速」。
5. 结论：给出阶段 + 该阶段核心看什么（导入看赛道、成长看渗透斜率、成熟看集中度）。
6. 敏感性：若总容量口径 ±20%，阶段结论是否翻转？翻转则说明结论脆弱，提示风险。

**判断句式**：根据【XX 行业】当前渗透率 P=X%，处于【成长期】，渗透增速 g=+X%/年；未来核心看 SAM÷TAM（见维度3）是否维持快速提升，预计高增长约还剩 X 年。

**小白翻译**：渗透率就像「智能手机在人群里的普及率」。10 人里 1 人用=刚起步；5 人用=正疯涨；9 人用=只能抢别人客户。不同阶段该关心的重点完全不同。

## 维度 2 · 商业模式可行性（UE 模型）

**方法卡**

| 项 | 内容 |
|----|------|
| 回答什么问题 | 这门生意怎么把钱赚到手？扩规模后会不会更赚？ |
| 用什么方法判 | 顺流拆解（进什么料→做什么→卖给谁→怎么收钱→留下什么）+ 最小运作单位 UE 模型 |
| 判据是什么 | UE（单位经济）> 0 才值得规模扩张；现金循环周期越短越健康 |
| 需要哪些数据 | 客单价、单客直接成本、单客分摊（获客/管理/研发）、存货/应收周转天数 |

**字段级取数公式**

```
UE = 客单价 − 单客直接成本(料+工) − 单客间接摊销(获客+管理+研发)
毛利率 = (收入 − 直接成本) ÷ 收入
现金循环周期 CCC = 存货周转天数 + 应收周转天数 − 应付周转天数
```

**推导模板**

1. 画资金流：用 flow 图把「钱从哪进、到哪出」画出，标出卡脖子（如获客成本畸高）。
2. 算 UE：套公式算单客利润，是否 > 0。
3. 算周转：算 CCC，判断营运资金占用。
4. 结论：UE>0 且 CCC 可控→规模扩张有意义；否则「规模越大亏越多」。

**判断句式**：这门生意本质【XX】，单位经济 UE=¥X > 0，扩规模有意义；但现金循环周期 X 天，对营运资金要求较高，需跟踪应收账款质量。

**小白翻译**：重点不是「赚不赚钱」，而是「每多接一单是不是更赚」。UE>0=卖一个赚一个；UE<0=卖得越多亏越多。现金循环周期=从垫钱到收回钱要等多久，越短越不需借钱周转。

## 维度 3 · 市场规模与空间（TAM/SAM/SOM 阶段化）

**方法卡**

| 项 | 内容 |
|----|------|
| 回答什么问题 | 生意天花板多高？离天花板还差多少空间？ |
| 用什么方法判 | TAM/SAM/SOM 阶段化 + 自上而下 × 自下而上两法交叉验证 |
| 判据是什么 | 导入期只看 TAM；成长期看 SAM÷TAM（≈渗透率斜率）；成熟期看 SOM÷SAM（市占率逻辑）。两法差距 >30% 必须解释 |
| 需要哪些数据 | 总人口/总设备量、客单价、行业年销量、公司销量、可比公司销量合计 |

**字段级取数公式**

```
TAM = 总人口(或总设备) × 客单价              # 理论天花板
SAM = TAM × 可服务细分渗透率                  # 目标细分市场
SOM = 公司当前销量 × 客单价                   # 已吃到的份额
成长期看 SAM÷TAM（≈渗透率，判高增长还能持续多久）
成熟期看 SOM÷SAM（市占率，逻辑转集中度提升）
空间余量 = (1 − 当前渗透率) × TAM
CAGR = (终值 ÷ 初值)^(1/年数) − 1
```

**推导模板**

1. 自上而下：总量 × 渗透率 × 客单价 → TAM/SAM。
2. 自下而上：单客户价值 × 客户数 × 玩家数 → 交叉算规模。
3. 交叉比对：两法差距 > 30% 必须解释（口径差异 or 漏算）。
4. 给区间：取两法重叠区间为「市场规模」，避免单一数字虚假精确。

**判断句式**：TAM ≈ ¥X 亿，当前渗透率 X%，空间余量 ≈ ¥X 亿；成长期 SAM÷TAM 年化 +Xpct，高增长约还剩 X 年。两法交叉验证差距 X%，合理。

**小白翻译**：TAM 是理论最大盘子，SAM 是你能碰到的块，SOM 是你已吃下的。关键不是盘子多大，而是「还能长多久」——成长期看渗透率还能涨多少，成熟期看你能从对手嘴里抢多少份额。不能只甩总数，必须说清怎么算的、靠不靠谱。

## 维度 4 · 护城河与防守性（5×4 矩阵）

**方法卡**

| 项 | 内容 |
|----|------|
| 回答什么问题 | 公司有没有挡住对手的真城墙？还是只是暂时跑得快？ |
| 用什么方法判 | 5×4 生产要素 × 生产关系矩阵——逐格判断公司在哪一格具备别人难复制的优势。**成本优势是结果不是原因** |
| 判据是什么 | 护城河成立三问：①难复制？②可持续？③对手无法用钱买断？任一不满足则该格优势不成立 |
| 需要哪些数据 | 专利数/研发投入、市占率趋势、客户留存/转换成本证据、资源排他性（牌照/矿权）、数据壁垒 |

**5×4 矩阵（生产要素 ＼ 生产关系）**

| 生产要素 ＼ 关系 | 政府 | 同行 | 供应商 | 客户 |
|----------------|------|------|--------|------|
| 劳动力 | — | 人才壁垒 | — | — |
| 土地/资源 | 牌照/矿权排他 | 区位垄断 | — | — |
| 资本 | 融资便利 | 规模门槛 | — | — |
| 技术 | — | 专利护城河 | — | 技术黏性 |
| 数据 | — | — | — | 转换成本/网络效应 |

> 表中「—」表示该组合通常不是护城河主战场。实际落地逐格填「强/中/弱/无 + 证据」。

**推导模板**

1. 铺矩阵：画 5×4 格子，逐格判断该公司是否占优，填「强/中/弱/无」。
2. 三问验证：对每张「强/中」格跑护城河三问，剔除「靠钱能买断」的伪护城河。
3. 反向追问：若写「成本低」，必须追问低成本来自哪个要素/关系（技术？规模？资源？），落到矩阵具体格。
4. 结论：汇总占优格，给「高/中高/中/低」护城河评级。

**判断句式**：公司在【技术 × 客户】格具备强护城河（专利 + 高转换成本），但【资本 × 政府】格弱；整体护城河评级中高，且验证「难复制、可持续、对手无法用钱买断」。

**小白翻译**：别只说「有品牌、有成本优势」这种形容词，要问「优势到底来自哪？对手花钱能不能马上抄走？」。低成本不是原因，是结果——指出来自技术更先进/规模更大/独家矿权。能用钱买断的优势，都不是真护城河。

## 维度 5 · 竞争格局与盈利性（CR8 三分类）

**方法卡**

| 项 | 内容 |
|----|------|
| 回答什么问题 | 蛋糕被几家分？格局固化没？龙头稳不稳？ |
| 用什么方法判 | CRn 集中度 + 梯队划分 + 波特五力（简化为对手/上下游/替代品） |
| 判据是什么 | CR8 三分类（下表）；梯队看份额位次与同比变化 |
| 需要哪些数据 | TOP10 玩家市占率、同比变化、龙头净利率 vs 行业均值（**须列可比公司**） |

**CR8 三分类（书中最好用的一把尺子）**

| CR8（前 8 家市占率之和） | 格局类型 | 含义 |
|------------------------|---------|------|
| CR8 < 40% | **竞争型** | 玩家散、价格战频发、座次未定，变数大 |
| 40% ≤ CR8 < 70% | **低集中寡占型** | 龙头初显，集中度在提升，是「押注赢家」好窗口 |
| CR8 ≥ 70% | **极高寡占型** | 格局固化，龙头定价权强，但超额收益已被 price in |

**字段级取数公式**

```
CRn = 前 n 家市占率之和（通常取 CR3 / CR5 / CR8）
份额变化 Δ = 今年份额 − 去年份额
相对盈利 = 龙头净利率 − 行业净利率均值
```

**推导模板**

1. 取 TOP10：列 TOP10 玩家份额与同比变化（带来源）。
2. 算 CR8：加总前 8 家，对照三分类读格局类型。
3. 看梯队：标出第一/二梯队与长尾，看位次是否变动。
4. 比盈利：龙头净利率 vs 行业均值，判断「份额优势是否转化为利润优势」。

**判断句式**：行业 CR8 = X%（低集中寡占型），格局尚未固化；龙头份额 X% 同比 +Xpct，集中度在提升，处于「押注赢家」窗口；龙头净利率高于行业均值 Xpct，份额优势已转化为利润。

**小白翻译**：CR8 是「前 8 家加起来的份额」：低于 40% 大家在混战；40%–70% 龙头刚冒头还在抢地盘（研究价值最高）；超 70% 座次已定，好东西价格也早被市场知道。报告必须列具体玩家和份额，不能只说「竞争激烈」。

## 维度 6 · 估值分析（总公式 + 阶段化）

**方法卡**

| 项 | 内容 |
|----|------|
| 回答什么问题 | 公司现在卖得贵不贵？相对自己和同行在什么位置？ |
| 用什么方法判 | 总公式：市值 = 净利润 × 估值倍数；再按阶段选 PE / PEG / PB / PS |
| 判据是什么 | 成长股看 PEG（<1 相对便宜）；周期股看历史分位 + 避开「高点低 PE 陷阱」；必须给「相对（同业）+ 绝对（历史）」双视角 |
| 需要哪些数据 | 当前 PE/PB/PS、同业中位数、5 年历史分位、未来 3 年净利 CAGR |

**字段级取数公式**

```
市值 = 净利润 × PE            # 总公式
PEG = PE ÷ (未来3年净利CAGR × 100)   # PEG < 1 相对便宜
隐含回报 = 1÷PE + 增速         # 持有视角的年化回报
周期股：用 PB / 历史分位，且须排除「盈利高点→低 PE 假便宜」
```

**阶段化估值法（与生命周期联动）**

| 阶段 | 推荐估值法 | 原因 |
|------|-----------|------|
| 导入期 | P/S、PEG、情景 DCF | 无利润，只能看收入 |
| 成长期 | PEG、P/S、EV/Revenue | 利润尚不稳，收入增速更关键 |
| 成熟期 | PE、PB、股息率、DCF | 利润稳定，传统估值有效 |
| 衰退期 | PB、清算价值、股息率 | 关注资产底部 |

**推导模板**

1. 定阶段：先用维度1结论定生命周期，选对应估值法。
2. 取倍数：取当前 PE/PB/PS + 同业中位数 + 5 年历史分位。
3. 双视角比：相对（同业分位）+ 绝对（历史分位）各给结论。
4. 排陷阱：周期股验证当前盈利是否处高点；低 PE 验证盈利是否可持续（排除价值陷阱）。

**判断句式**：当前 PE X 倍，处历史 X% 分位、同业 X% 分位；按成长股 PEG=X（合理/偏贵）；已排除「周期高点低 PE」陷阱，估值结论有效。

**小白翻译**：核心公式一句话——公司总价值 = 每年赚的钱 × 一个倍数。倍数高说明市场愿为每块钱利润付更多，可能贵了。但光看 PE 会踩坑：周期股利润最高点时 PE 反而最低（假便宜），盈利快消失的「低 PE」其实是贵。必须同时看「比同行贵不贵」和「比自己历史贵不贵」。

## 维度 7 · 外部因素（PEST 五段传导链）

**方法卡**

| 项 | 内容 |
|----|------|
| 回答什么问题 | 行业外面的风（政策/经济/社会/技术）会怎么吹动这门生意？ |
| 用什么方法判 | PEST 五段传导链：事实 → 传导路径 → 影响对象 → 量级 → 兑现时点。**不再只罗列现象** |
| 判据是什么 | 每个外部因素必须走完五段链；区分「已落地政策」与「预期政策」（后者计入股价程度不同） |
| 需要哪些数据 | 政策文件/生效日、利率/GDP/可支配收入、人口结构、替代技术成熟度 |

**推导模板（五段链，每个因素必走）**

1. 事实：写清「发生了什么」（文件/数据），带来源与日期。
2. 传导路径：它怎么一步步影响到收入或成本（如 补贴退坡 → 终端涨价 → 销量降）。
3. 影响对象：受影响的是收入端、成本端、还是估值端？
4. 量级：给个区间（±X% 净利），无法量化标「定性，待跟踪」。
5. 兑现时点：写清「什么时候见效」（如 2026Q4），区分已落地 vs 仅预期。

**判断句式**：外部因素整体【中性偏正】。X 政策已落地，经【价格→利润】传导，预计影响 +X% 净利、2026Q4 兑现；Y 技术替代风险为定性待跟踪项，需持续监测。

**小白翻译**：外部因素就是「生意外面的风」。过去只说「政策利好」废话。正确做法是把风怎么吹进窗户说清楚：补贴退了→车变贵→买的人少→少赚 X%→明年见效。说不出传导路径的「利好」基本是安慰剂。

## 维度 8 · 景气度跟踪（指标看板）

**方法卡**

| 项 | 内容 |
|----|------|
| 回答什么问题 | 生意现在热不热？升温/筑底/降温？拐点快到了吗？ |
| 用什么方法判 | 景气指标看板：每行业定义 3–5 个核心指标（量/价/库存/订单）+ 跟踪频率 + 拐点信号 |
| 判据是什么 | 指标连续 2 期反转 = 拐点信号；库存周期位置 + 产能利用率辅助确认 |
| 需要哪些数据 | 产量/出货同比、产品单价环比、产成品存货同比、新订单/招标量、产能利用率 |

**指标框架（须按行业定制）**

| 维度 | 代表指标 | 频率 | 上行信号 |
|------|---------|------|---------|
| 量 | 产量/出货量/装机量（同比） | 月/季 | 同比加速 |
| 价 | 产品单价/吨利润（环比） | 周/月 | 环比上涨 |
| 库存 | 产成品存货同比 | 月 | 同比去化（下降） |
| 订单 | 新订单指数/招标量 | 月 | 持续放量 |
| 产能 | 产能利用率 | 季 | 回升至高位 |

**判断句式**：当前景气度【上行/筑底/下行】——价格环比 +X%、库存同比 −X%、产能利用率 X%；需重点跟踪【X 指标】是否连续 2 期反转，作为拐点确认信号。

**小白翻译**：光说「行业景气」没用，得说清看哪几个温度计、多久量一次、什么读数算变天。量涨/价升/库存去化/订单饱满同时出现=热；反过来=冷。最值钱的是拐点信号：指标连续两期反转，往往比新闻早一步告诉你趋势要变。
