# 八维分析 · 小白化规范（plain-language）

> 本 Skill 的受众是**普通投资者（投资小白）**，不是专业机构。凡面向读者的表述，必须遵循本规范：让小白读得懂、学得会、能顺着链接自己验证。
> 配合 [book-criteria.md](book-criteria.md) 的「小白翻译」段与 [output-spec.md](output-spec.md) 的阅读结构共同生效。
>
> **v1.2（2026-08-18）**：新增「人话卡」三行组件模板（§四），原「小白翻译块」升级为强制人话卡机制，与 template.html 的 `.human-term-card` 组件对应。

---

## 一、三层阅读结构（同一份报告，三种读法）

| 层 | 名称 | 给谁看 | 内容 |
|----|------|--------|------|
| ① | 摘要层（30 秒） | 只想拿结论 | 章末「一句话」+ 文末综合结论卡 |
| ② | 分析层（10 分钟） | 想搞懂为什么 | 方法卡 + 关键数据 + 推导过程 |
| ③ | 来源层（随时） | 想自己验证 | 每个数字的角标链接 + 文末来源表 |

> 报告结构必须支持三层：摘要层可被快速扫读，分析层解释判据，来源层可顺藤摸瓜。

---

## 二、术语即时解释

- **首现括注**：专业词第一次出现，紧跟一句大白话。例：「CR8（前 8 家公司的市场份额加起来）」。
- **缩写翻译**：禁用无解释缩写。例：「戴维斯双击」→「盈利和估值一起涨，双击」；「UE」→「单位经济（卖一个能赚多少）」。
- **英文保留但附中文**：PE / PEG / ROIC 等可保留，但首次出现必须给中文释义。

---

## 三、术语首现注释库（正文强制，禁止跳过）

> **核心规则**：以下术语在报告正文中**首次出现时**，必须紧跟一句大白话括注。格式：`UE（单位经济，卖一个能赚多少）`。方法卡、推导过程、数据来源区不受此限（那些是给想深究的人看的）。

| 术语 | 首现括注（≤20字，一句大白话） | 常见错误（禁止） |
|------|---------------------------|----------------|
| 渗透率 | 已有用户÷潜在用户总数 | 只写公式不给人话 |
| UE / 单位经济 | 客单价减去直接成本和分摊，每单净赚 | 写「单位经济模型」不解释 |
| 毛利率 | 每卖 100 元去掉直接成本后剩多少 | 只给公式不翻译 |
| CCC / 现金循环周期 | 垫钱进货到收回现金要等多少天 | 写「营运资金周期」不解释 |
| TAM | 理论最大市场，所有人×客单价 | 只甩英文不翻译 |
| SAM | 能服务到的市场，TAM 里的目标人群 | 与 TAM 混用 |
| SOM | 已吃下的市场份额，基于当前销量算 | 与 SAM 混用 |
| CAGR | 复合年增速，把多年增速摊成年化 | 写「年复合增长率」不解释 |
| CRn / CR8 | 前 N 家市占率加起来 | 只写「集中度」不解释 n 几 |
| PE | 市值÷净利润，理论回本年限 | 写「市盈率」后不翻译 |
| PEG | PE 除未来增速，看为增长付溢价贵不贵 | 只给公式不给人话 |
| PB | 市值÷净资产，清算视角的贵不贵 | 写「市净率」后不解释 |
| PS | 市值÷营收，没利润时看收入倍数 | 只给缩写不翻译 |
| ROIC | 投入资本回报率，看资本赚不赚钱 | 写「资本回报率」不解释 |
| PEST | 政策/经济/社会/技术四类外部因素 | 只列四个字母不翻译 |
| 5×4 矩阵 | 5 种生产要素×4 种生产关系，找难复制优势 | 只写「生产要素矩阵」不解释 |
| 波特五力 | 同业/新进入/替代品/供应商/客户五方博弈 | 写英文不翻译 |
| 产能利用率 | 实际产量÷理论产能，判断工厂忙不忙 | 只写百分比不解释含义 |

> **使用规则**：生成报告时，AI 须在对应维度的正文中首次出现上述术语时立即括注。同一报告内重复出现时可省略括注，但若跳转到另一维度章节，则该维度内首次出现仍需括注（维度间不继承）。

## 四、人话卡模板（v1.2 新增，每维度强制）

> 报告正文用 `.human-term-card` 组件承载（template.html 已内置样式与深色适配）。**每个维度至少 1 张**，放在术语首次出现的正文段落之后。
> **三行固定结构**：`术语：`（加粗）→ `大白话一句话` → `生活类比（就像…）`。

```html
<div class="human-term-card">
  <span class="ht-icon">💬</span>
  <div class="ht-body">
    <span class="ht-term">CR8：</span>
    <span class="ht-plain">前 8 家公司的市场份额加起来的数字。就像班里前 8 名同学的总分占比——占比越高，说明头部垄断越明显。</span>
  </div>
</div>
```

**填空规则**：
- `ht-term` = 术语名 + 冒号（术语取自「§三 术语首现注释库」表头）
- `ht-plain` = 「§三」表的首现括注（≤20 字大白话）+ 「§五」表的生活类比拼接
- 每维度内首次出现的**每个**术语都要有对应人话卡；维度间不继承，跳维后再出现仍需新卡（与首现括注规则一致）
- 术语密集处可把多个相关术语合并进一张卡（如 TAM/SAM/SOM 三连解释）

## 五、生活类比机制

每维度必须配 **≥1 张人话卡**（见 §四），`ht-plain` 中的生活类比从下表取，用生活场景类比抽象概念：

| 抽象概念 | 生活类比 |
|---------|---------|
| 渗透率 | 智能手机在人群里的普及率 |
| 护城河 | 挡住对手的城墙 |
| 商业模式 UE | 每多接一单是不是更赚 |
| 市场规模 TAM/SAM/SOM | 理论最大盘子 / 能碰到的块 / 已吃下的 |
| CR8 集中度 | 前 8 家分到的蛋糕比例 |
| 估值 PEG | 为每块钱利润付的溢价贵不贵 |
| PEST | 生意外面的风怎么吹进窗户 |
| 景气度 | 生意现在热不热，看哪几个温度计 |

## 六、反例 → 正例对照

写作时自检，把「机构黑话」改为「小白能懂的话」：

| 反例（废话） | 正例（说清传导） |
|------------|----------------|
| 「政策利好」 | 「补贴退坡 → 车变贵 → 买的人少 → 少赚 X%」 |
| 「行业景气」 | 「量涨、价升、库存去化、订单饱满，四个同时出现=热」 |
| 「竞争格局良好」 | 「CR8=52%，低集中寡占，龙头份额同比 +3pct，还在抢地盘」 |
| 「估值合理」 | 「PE 25 倍，处历史 40% 分位、同业 35% 分位，PEG=0.9 偏便宜」 |
| 「具备护城河」 | 「技术×客户格有专利+高转换成本，对手花钱抄不走」 |

## 七、禁用清单

- 不堆砌无解释英文缩写。
- 不写「众所周知」「显然」「不言而喻」等敷衍过渡。
- 不把结论当推导（必须先有方法卡+推导，再给结论）。
- 不假设读者有财务背景（默认读者不懂 ROIC/EBITDA，首现必释）。
