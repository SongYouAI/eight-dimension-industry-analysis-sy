# 八维分析 · 数据采集清单（data-requirements）

> 本文件是 Phase 1 数据采集的**字段级**依据。采集阶段必须按本表取数，每条数据入库时强制记录**六元组**，缺任一项不得进入报告。
> 与 [book-criteria.md](book-criteria.md) 一一对应：每个字段都能在判据总表找到出处与公式。

---

## 六元组记录制（每条数据必填）

采集到的每一条数据，必须同时记录以下六个字段，缺任一项该数据不得写入报告：

```
{ 数值, 口径说明, 来源URL, 页面标题, 发布日期, 抓取日期 }
```

- **数值**：具体数字（带单位）。
- **口径说明**：分子分母口径、统计范围（如「出货量 vs 零售量」「全球 vs 中国」）。
- **来源URL**：可点击、点开能直接找到该数字的页面（见 [output-spec.md](output-spec.md) 四级颗粒度）。
- **页面标题**：该 URL 的页面标题，便于无链接时回溯。
- **发布日期**：来源发布日期；超 1 年标 `[过时]`。
- **抓取日期**：本次采集日期，用于时效性审计。

**降级写法**（无稳定 URL 时）：`{机构} · 《{报告全名}》 · {发布日期} · P{页码}`，且必须在文末来源汇总表登记并标注「无公开链接」。

## 字段级采集清单

| 字段 | 维度 | 取数口径 | 来源类型 | 必填 |
|------|------|---------|---------|------|
| 年销量 / 用户数 | ① ③ | 行业年度出货量或累计用户，注明统计口径（出货 vs 零售） | 协会/行研 | ✅ |
| 理论总容量 | ① ③ | 潜在保有量上限或政策规划目标，须与分子同口径 | 行研/统计 | ✅ |
| 渗透率 P 与增速 g | ① | 由公式算出，保留两位小数 | 计算 | ✅ |
| 客单价 / 单客成本 | ② | UE 模型分子分母，区分直接/间接 | 财报/调研 | ✅ |
| 现金循环周期 CCC | ② | 存货+应收−应付周转天数 | 财报计算 | ⬜* |
| TAM / SAM / SOM | ③ | 阶段化空间，两法交叉验证 | 计算 | ✅ |
| 5×4 护城河矩阵 | ④ | 逐格「强/中/弱/无 + 证据」 | 财报/专利/调研 | ✅ |
| TOP10 市占率 + Δ | ⑤ | 含同比变化，必须列可比公司 | 协会/行研 | ✅ |

| 龙头 vs 行业净利率 | ⑤ ⑥ | 份额优势是否转化为利润 | 财报 | ✅ |
| 当前 PE / PB / PS | ⑥ | 公司及同业中位数 | 行情/财报 | ✅ |
| 历史分位（5Y） | ⑥ | 估值所处历史百分位 | 行情 | ✅ |
| 未来 3 年净利 CAGR | ⑥ | 用于 PEG / 隐含回报 | 一致预期 | ✅ |

> ⬜* = 有条件必填：商业模式涉及重资产 / 营运资金敏感时 CCC 必填。

## 采集纪律

1. **先假设后采集**：Phase 0.5 假设清单驱动采集重点，避免被海量信息淹没。
2. **分组并行**：按 SKILL.md Phase 1 的 A/B/C/D/E 五组并行，不过度消费 token。
3. **交叉验证**：关键数字（渗透率/CR/规模/PE）至少 2 个独立来源，否则标 `[待验证]`。
4. **入库即带六元组**：采集阶段就把六元组写进数据池，写作阶段只消费已核验数据，杜绝「边写边编数」。
5. **无链接不裸名**：来源必须是可点击链接或降级署名，禁止只写机构名。
